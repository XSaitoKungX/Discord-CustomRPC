## What this project is

Discord Custom RPC Manager — a cross-platform Electron desktop app (Windows,
macOS, Linux) for creating, managing, and activating custom Discord Rich Presence
profiles. Open source (MIT), free. Version `2.0.0`.

## Tech stack

- Electron 41, React 19, TypeScript.
- Tailwind CSS v4, Radix UI, shadcn-style components, Lucide icons.
- Zustand state, `react-router-dom` hash router.
- Main process: `better-sqlite3`, `drizzle-orm`, `discord-rpc`, `electron-updater`.
- Build: `electron-vite`, `electron-builder`. Package manager: **Bun** only.

## Environment setup

```bash
bun install
bun run prepare:native   # if better-sqlite3 fails to load
```

## Common commands

```bash
bun run dev          # dev server (renderer port 7000)
bun run build:full   # generate migrations + production build
bun run lint         # eslint src/
bun run typecheck    # tsc --noEmit
bun run db:generate  # create migration from src/db/schema.ts
```

## Code style

- TypeScript everywhere; `any` is forbidden (`no-explicit-any` is an eslint error).
- Prettier config: no semicolons, single quotes, 2-space indent, no trailing
  commas, `printWidth` 100, always parenthesize arrow params.
- Keep all imports at the top of files.
- Do not add or delete comments unless explicitly requested.
- Renderer aliases: `@` and `@renderer` map to `src/renderer/src`.

## Where things live

- `src/main/` — Electron main process (lifecycle, window, tray, updater, deeplink).
- `src/main/ipc/` — IPC handlers: `profiles.ts`, `rpc.ts`, `settings.ts`.
- `src/preload/index.ts` — contextBridge exposing `window.api`.
- `src/db/` — Drizzle schema, init/migrations, queries.
- `src/renderer/src/` — React app: `pages/`, `components/`, `store/`, `hooks/`,
  `lib/`, `styles/`, `types/`.

## How to add a feature

1. Add or extend an IPC handler in `src/main/ipc/<domain>.ts`.
2. Expose it through `src/preload/index.ts` as `window.api.<domain>.<method>`.
3. Consume it from a Zustand store in `src/renderer/src/store/` and the UI.
4. For DB changes, edit `src/db/schema.ts` then run `bun run db:generate`. Never
   hand-edit files in `src/db/migrations/`.

## Validation (run before finishing)

```bash
bun run typecheck
bun run lint
```

Both must pass. Keep diffs minimal and scoped to the task.

## Constraints

- Never bypass the preload bridge; the renderer must not import Node/Electron.
- Keep `contextIsolation: true`, `nodeIntegration: false`.
- Never hardcode secrets. The Discord Application ID is user-supplied input.
- Routing must use the hash router (production loads from `file://`).
